# Voxel Galaxie

Ein Voxel-Open-World-Spiel im Browser — eine Datei, kein Build, kein Server.

**Spielen:** https://mikkel-thiemann.github.io/voxel-galaxie/

## Was drin ist
- Offene Welt aus Blöcken, 1800 × 1800 Blöcke, per Chunk-Streaming nachgeladen
- Vier Regionen: Wüste, Eisplanet mit Schneesturm, Waldmond, Lavawelt mit fliessendem Magma
- Questgeber mit Missionen, Kampf mit Laserschwert und Machtkräften
- Fahrzeuge: Gleiter, Jäger und ein grosser Frachter — mit Luftkampf gegen Grosskampfschiffe
- Konten mit Sicherungscode, Münzen, Shop mit Stufen-Aufwertungen

## Steuerung
| Taste | Wirkung |
|---|---|
| W A S D / Maus | Laufen, Umsehen |
| Shift / Leertaste | Sprinten, Springen |
| Linksklick | Schwert bzw. Laser |
| E / F | Reden, Fahrzeug ein-/aussteigen |
| Q / G / Z / H | Machtstoss, Macht-Griff, Blitz, Heilung |
| M / T / X | Karte, Sprungpunkte, Shop |
| U / K | Befreien, Sicherungscode |

Technik: Three.js r128, eigener Chunk-Mesher mit Face-Shading und Ambient Occlusion,
Schattenwurf, Bloom und prozedurale Weltgenerierung.

Privates Fan- und Lernprojekt, nicht kommerziell.
